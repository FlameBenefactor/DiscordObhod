> [!WARNING]

> ### РЕАКЦИЯ АНТИВИРУСОВ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret требуется WinDivert — инструмент, который перехватывает и фильтрует трафик.
> Его применяют как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусные программы классифицируют файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляют их либо отправляют в карантин. В названии такого обнаружения обязательно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Можно добавить каталог с zapret в исключения антивируса или выключить обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky для этого предусмотрен пункт «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы умеете безопасно настраивать исключения, рекомендуется использовать их; если не уверены в своих действиях, лучше отключить обнаружение PUA.

## ⚙️Как пользоваться

1. Настройте Безопасный DNS (Secure DNS)
    * Chrome: включите «Использовать безопасный DNS» и укажите поставщика DNS, выбрав не вариант «Поставщик по умолчанию»
    * Firefox: откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную укажите URL. Подойдёт, например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах системы — воспользуйтесь [этой инструкцией](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 рекомендуется именно этот способ
    * На роутере Keenetic включите параметр «Транзит запросов». Если он отключён, при настройке и использовании Secure DNS на компьютере могут возникнуть проблемы

2. Откройте [страницу последнего релиза](https://github.com/FlameBenefactor/zapret-discord-youtube/releases/latest) и загрузите архив в формате zip или rar

3. Откройте свойства архива и отметьте пункт «Разблокировать». При распаковке через 7-Zip или PeaZip этот шаг не нужен

4. Извлеките архив в каталог, путь к которому не содержит кириллицы и специальных символов

5. Запустите подходящий файл
    * Чтобы определить рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы добавить её в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск выбранной стратегии

  Этот вариант удобен для проверки стратегий. Их работоспособность зависит от множества условий, поэтому **поочерёдно проверяйте ALT, FAKE и остальные стратегии, пока не найдёте подходящее решение**

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные возможности:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаляет из служб стратегию и WinDivert
  - **`Check Status`** — показывает состояние обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — меняет режим обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — управляет обходом сервисов, перечисленных в `ipset-all.txt`.  
  Этот режим полезен при проверке ресурса, который открывается без zapret, но не работает вместе с ним.  
  В скобках показывается один из статусов:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP-адреса в списке
    - `any` — под фильтрацию попадает любой IP-адрес  
  - **`Auto-Update Check`** — включает или отключает автоматический поиск обновлений
  - **`Replace active fakes`** — заменяет указанный активный фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загружает из репозитория актуальную версию `ipset-all.txt`
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ищет доступные обновления
  - **`Run Diagnostics`** — проверяет распространённые причины, из-за которых zapret может не работать.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, если приложение внезапно перестало подключаться
  - **`Run Tests`** — открывает инструмент проверки работоспособности стратегий:
    - `Standard tests` — тестирует сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` — выполняет проверку DPI у разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неполадки

### После открытия скрипта `general*` ничего не происходит

- При ручном запуске стратегии отдельным bat-файлом, а не через service, должен запуститься winws.exe — его значок обхода появится на панели задач.  
Если этого не случилось, ознакомьтесь с [#522](https://github.com/FlameBenefactor/zapret-discord-youtube/issues/522)

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- После этого перезагрузите компьютер

### Не открывается веб-версия Telegram
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из автоматически открывшегося Блокнота
  - В появившейся папке найдите `hosts` и откройте его текстовым редактором, запущенным от администратора
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленный похожий фрагмент
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения в `hosts` действительно сохранились

#### Работоспособность этого способа не гарантируется. Если он не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/FlameBenefactor/tg-ws-proxy) либо любой публичный прокси.

### Обход перестал работать или не запускается

> [!IMPORTANT]
> **Любая стратегия со временем может потерять работоспособность.**
> Даже если определённый вариант некоторое время помогал, после обнаружения он может перестать работать.
> В репозитории собрано много разных стратегий обхода. Если подходящей среди них нет, создайте новую на основе одной из существующих, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и устраните найденные ошибки

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов либо IP-адресов

- Протестируйте остальные стратегии, включая **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация приведена в [#765](https://github.com/FlameBenefactor/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сначала сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Затем запустите `service.bat` -> `Run Diagnostics`, исправьте ошибки при их наличии и в конце нажмите Y
- Удалите каталог с zapret
- Загрузите актуальную сборку `zapret-discord-youtube-...` [со страницы релизов](https://github.com/FlameBenefactor/zapret-discord-youtube/releases)
- Щёлкните по архиву правой кнопкой мыши и откройте свойства. Если справа внизу доступен пункт разблокировки, отметьте его, нажмите «Применить», затем «ОК»
- Распакуйте файлы в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы
- Поочерёдно запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступ к интернет-ресурсам. Если вариант не сработал, закройте программу через значок замка на панели задач и попробуйте следующий
- Найденную рабочую стратегию можно добавить в автозапуск: `service.bat` -> `Install Service` -> выберите нужный вариант

### Игра или приложение не работает при включённом zapret

- Убедитесь, что в `service.bat` для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно повлиять на доступность ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert остаётся в системе

1. Откройте командную строку Windows через Win+R и `cmd`, затем определите имя службы:

```cmd
driverquery | find "Divert"
```

2. Подставьте найденное имя и выполните команды остановки и удаления:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fкак-пользоваться)
- Выключите блокировщик рекламы: известно, что YouTube начал бороться с такими расширениями
- Переберите остальные стратегии, особенно если прежняя раньше работала, а затем перестала
- Дополнительные сведения есть в [#251](https://github.com/FlameBenefactor/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fкак-пользоваться) настроен
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить именно её
- Откройте `service.bat` -> `Run Diagnostics` и очистите кэш Discord
- После очистки снова проверьте приложение Discord
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если соединения нет и в браузере, снова проверьте все стратегии: иногда YouTube работает с определённой стратегией, а Discord — нет
- См. также обсуждение [#252](https://github.com/FlameBenefactor/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/FlameBenefactor/tg-ws-proxy)
- Другой вариант — бесплатные MTProto-прокси из интернета

### Возникли проблемы с играми

Игр очень много, поэтому исследовать и исправлять работу каждой из них невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, а затем включите `Game Filter`
- если результата нет, дополнительно активируйте `ipset any`

Учтите, что режим `ipset any` мешает открытию многих сайтов, поэтому не оставляйте его включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если предложенные действия не помогли, создайте тему в разделе [Discussions](https://github.com/FlameBenefactor/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

## 🗒️Как добавить адреса других ресурсов

Чтобы расширить перечень адресов для обхода, используйте следующие файлы:
- **`list-general-user.txt`** — домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети присутствует в `ipset-all.txt`, но отдельный домен этой сети фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Все файлы вида **`*-user.txt`** создаются автоматически при первом запуске `zapret` либо `service.bat`
